## 观察者模式（观察者模式中主体和观察者是互相感知的）

```
Subject -------------->  Observe
           file event

Subject <--------------  Observe
           subscrible
```

## 发布订阅模式（借助第三方来实现调度的，发布者和订阅者之间互不感知）

```
Publisher ----------------> ChangeManager ---------------> Subscriber
           publish event                     file event

Publisher <---------------- ChangeManager <--------------- Subscriber
              subscrible                     subscrible
```

## 使用场景

```
发布订阅模式适合使用在较为复杂的场景，比如：

在一对多的场景下，发布者的更新只想通知他的部分订阅者？
在多对一或者多对多的场景下，一个订阅者依赖多个发布者，某个发布者更新后是否需要立即通知订阅者？还是等所有的发布者都更新完毕再通知订阅者？

这些复杂逻辑都可以放在ChangeManager里面

观察者模式只适合简单的场景：

主体更新将通知他的所有观察者
```
