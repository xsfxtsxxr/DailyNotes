### Http1.x

```
http1.x 发起请求会创建一个 TCP 连接，虽然开启 keep-alive 解决了多次创建连接的问题，但是多个请求必须串行传输，第一个 http 请求必须完成，才能处理下一条 Http 请求（注：此项计算有一个前提条件，就是浏览器和服务器是单通道传输），如果并发就要创建多个 TCP 连接，但是浏览器有限制最大不能超过 6 个 TCP 连接，这样就会造成性能问题。
```

### Http2.0

```
http2.0 的多路复用就是为了解决以上问题，http2.0 有两个非常重要的概念，分别是帧（frame）和流（stream）。帧代表最小的单位，每个帧会有一个标识属于哪个流，流也就是由多个帧组成的数据流。多路复用就是在一个 TCP 连接中可以存在多条流，也就是可以发送多个请求，同一个域名下的所有 http 请求都可以在一个 TCP 连接中并发进行。这样可以有效避免对头阻塞，极大提高传输的性能。
```
